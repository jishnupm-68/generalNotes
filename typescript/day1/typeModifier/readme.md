
protected , private and public access modifiers are used here
instead of private we can also use "#"      => private: typescript and # : javascript
eg: private name and #name both treat as same 



| Keyword       | Accessible From            | Best For                                 |
| ------------- | -------------------------- | ---------------------------------------- |
| **public**    | Everywhere                 | General properties, methods              |
| **private**   | Only inside the same class | Completely hiding implementation details |
| **protected** | Same class + child classes | OOP inheritance cases                    |
